Movie Ticket Booking System

This is a simple Python project for booking movie tickets using the command line.

Requirements

Python 3

No extra libraries are required

How to Run
Step 1: Install Python

Download Python from:

https://www.python.org/downloads/

Check if Python is installed:

python --version

Step 2: Open the Project Folder

Open the terminal in the project folder where movie_booking.py is present.

cd movie-ticket-booking

Step 3: Run the Program
python movie_booking.py


For macOS/Linux, you can use:

python3 movie_booking.py

How the Project Works

The program allows the user to:

Select a city

Select a theater

Select a movie

Select a screen

Enter the number of tickets

Select the movie timing
